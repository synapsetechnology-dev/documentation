How it Works

Updated: Sep 2026 4 min read Architecture

Understanding the data lifecycle, execution engine, and modular event flow of Synapse Technology.

Core Architectural Flow

Synapse follows an event-driven decoupled architecture. When an action occurs (e.g. a customer makes a purchase, a webhook is fired, or a scheduled cron job executes), the core kernel dispatches an event through prioritized message queues.

1
Trigger Event Ingestion
Events arrive via HTTP Webhooks, Scheduled Cron jobs, or Admin UI interactions. Incoming payloads are validated against strict schema rules.
2
Conditional Logic Evaluation
The Synapse Workflow Engine processes the configured filter nodes (e.g., "if total > $50" or "if user status is active").
3
Action Execution & Dispatch
External API calls (OpenAI, Stripe, SMTP, Webhooks) are processed asynchronously in worker queues to guarantee sub-millisecond page response times.
Queue Worker Tip
For high-volume production setups, running Supervisor to monitor php artisan queue:work --tries=3 delivers optimal performance and fault tolerance.

Quick Start Guide

Setup: 5 mins Difficulty: Easy Installation

Follow this 3-step rapid setup guide to deploy Synapse to your production server or local testing environment.

Step 1: Upload Files & Set Permissions

Extract the zip file downloaded from CodeCanyon and upload the files inside the /script/ folder to your web server root (typically public_html or your Nginx/Apache virtual host directory).

bash 
# Ensure write permissions for storage and cache directories
chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data /var/www/html

Step 2: Create a MySQL Database

In your hosting control panel (cPanel, Plesk, CyberPanel, or MySQL CLI), create a new blank database:

  • Database Name: synapse_db
  • Database User: synapse_user
  • Collation: utf8mb4_unicode_ci

Step 3: Run the Web Installer

Open your browser and visit your site domain:

browser 
https://yourdomain.com/install

Password: admin123456
(Please change these credentials immediately upon first login!)

Syncing Your Tools

Connect your existing databases, third-party webhook relays, and external APIs with automated bi-directional synchronization.

Automated Cron Synchronization

To keep customer records, subscription statuses, and workflow queues in sync, add this single cron entry to your server:

crontab -e 
* * * * * cd /path/to/synapse && php artisan schedule:run >> /dev/null 2>&1

Real-Time Webhook Listeners

Synapse creates automated endpoints for each service. For instance, to sync Stripe customer payments, navigate to Admin > Integrations > Stripe and copy the pre-generated webhook URL into your Stripe Developer Dashboard.

Home Customization Introduction to the Builder

Introduction to the Builder

Master the drag-and-drop workflow canvas and front-end interface customizer included in Synapse.

Canvas Components

The builder consists of three main elements:

  • Trigger Nodes: Specify what starts the automation (form submission, new order, API call).
  • Decision Logic Nodes: Branch paths based on variable conditions, regex matching, or user attributes.
  • Action Nodes: Execute external tasks such as sending emails, writing database rows, or querying AI language models.
Pre-built Workflow Templates
Synapse includes 20+ ready-to-use automation templates for user onboarding, order confirmations, churn prevention, and lead scoring.

Connecting Third Party Tools

Configuring API Keys

All third-party credentials are securely stored using AES-256 encryption. To add your API keys:

  1. Go to Admin Dashboard > Settings > Integrations.
  2. Select the provider (e.g., Stripe, PayPal, OpenAI, or AWS S3).
  3. Paste your API Key, Secret Key, and Webhook Secret.
  4. Click Test Connection to verify valid authentication.
Home Advanced Features Installation & Requirements

Installation & Requirements

Detailed technical specifications, PHP extensions, and Apache/Nginx web server setup rules.

Server Prerequisites

  • PHP: Version 8.2 or 8.3
  • Database: MySQL 8.0+ or MariaDB 10.5+
  • Web Server: Apache (with mod_rewrite) or Nginx
  • Required PHP Extensions: BCMath, Ctype, cURL, DOM, Fileinfo, JSON, Mbstring, OpenSSL, PCRE, PDO, Tokenizer, XML, GD/Imagick, and Zip.

Nginx Configuration Example

/etc/nginx/sites-available/synapse.conf 
server {
    listen 80;
    server_name yourdomain.com;
    root /var/www/synapse/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php;
    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
