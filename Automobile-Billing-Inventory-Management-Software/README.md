# Automobile Billing & Workshop POS System — Documentation

Official offline-compatible HTML documentation for the **Automobile Billing & Workshop POS System** (Laravel 12 / PHP 8.2+ / MySQL 5.7+ / 8.0+).

- **Modern Interactive Web App**: Responsive off-canvas sidebar, Dark/Light mode theme switch, real-time Ctrl+K search modal, reading progress indicator, copyable code blocks with toast alerts.
- **100% Offline Compatible**: Can be viewed directly by double-clicking index.html in any web browser without needing a web server.
