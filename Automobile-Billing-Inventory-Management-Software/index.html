Automobile POS Product Overview

Automobile Billing & Workshop POS System

High-performance, modern, and feature-rich billing and shop management software designed specifically for automotive repair workshops, mechanic garages, car wash centers, and auto spare parts retailers.

Production-Ready CodeCanyon Architecture

Built with enterprise Laravel 12, Tailwind-styled responsive interfaces, and MySQL 5.7+ / 8.0+. Includes an automated 4-step web installer, 5 built-in invoice print layouts, unit conversions, WhatsApp customer alerts, and 1-click database backups.

Core System Highlights

4-Step Web Installer
Automated installation wizard checks PHP requirements, writable permissions, connects to MySQL, and migrates tables without touching command line.
5 Print Layouts (80mm & A4)
Built-in templates for Classic 80mm thermal receipt printers, Compact Pro (A4/A5), Creative Color, Detailed Corporate, and Modern Simple A4.
WhatsApp Direct Invoicing
1-click WhatsApp messaging dispatches invoice totals, due balances, and payment links directly to the client's mobile phone instantly.
Spare Parts & Unit Conversion
Track parts by Part Number, Brand, Category, and define sub-units (e.g., 1 Box = 10 Pcs, 1 Barrel = 200 LTR) with automatic inventory deduction.
Customer Ledgers & FIFO
Maintains real-time debit/credit account balances, printable statements, and automatic FIFO chronological settlement of pending invoices.
1-Click Backups & Utilities
Create full SQL database dumps stored securely in non-public storage with instant download, restore tools, and app cache flushing.

Automobile POS Web Installation Wizard

4-Step Web Installation Wizard

Deploy the entire software in under 3 minutes using the built-in graphical setup wizard without writing any command-line instructions.

1

Upload & Extract Main Files

Upload the contents of the Main_Files folder into your web hosting document root (e.g. public_html/ or a subdomain directory such as pos.yourdomain.com).

2

Access the Web Installer in Browser

Open your browser and navigate to the installer URL:

BROWSER URL 
https://yourdomain.com/install

If you visit the root domain https://yourdomain.com/ before installing, the system will automatically redirect you directly to the installation wizard.

3

Requirements & Permissions Verification

The wizard automatically runs an internal diagnostic checklist:

  • Validates PHP 8.2+ and all required extensions (BCMath, cURL, GD, Mbstring, PDO, OpenSSL, XML).
  • Verifies writable folder permissions for storage/, bootstrap/cache/, and public/uploads/ (chmod 0755 or 0775).

Click "Continue Setup" once all green checkmarks appear.

4

Database Connection & Administrator Account

Supply your MySQL credentials created in your cPanel / hosting panel:

  • Database Host: usually 127.0.0.1 or localhost
  • Database Port: 3306
  • Database Name: e.g., u123_automobile_pos
  • Database Username: e.g., u123_dbuser
  • Database Password: your secure database password

Use the "Test Database Connection" button to confirm connection. Next, create your Administrator Username and Password.

Click "Run Installation". The installer will write .env, generate APP_KEY, execute database migrations and seeders, create the admin user, and generate the lock file at storage/installed.

Installation Complete!

You can now click "Go to Login" and access your dashboard at https://yourdomain.com/login using your new administrator credentials.

Automobile POS Manual cPanel Install

Manual Installation via cPanel & phpMyAdmin

If you prefer manual database setup instead of the web installer wizard, follow this step-by-step procedure.

1

Create MySQL Database & User

Log into your cPanel → click MySQL Databases. Create a new database and database user with a strong password. Assign the user to the database with ALL PRIVILEGES.

2

Import Standalone database.sql

Open phpMyAdmin from cPanel, select your newly created database, click the Import tab at the top, choose the SQL file located in Database/database.sql from the master package, and click Go.

3

Configure .env File

In cPanel File Manager, locate .env.example, rename or copy it to .env, and edit your credentials:

.env CONFIGURATION 
APP_NAME="Automobile Billing Software"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourdomain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_cpanel_db_name
DB_USERNAME=your_cpanel_db_user
DB_PASSWORD=your_cpanel_db_password
4

Lock the Installer

Create an empty file named installed inside the storage/ directory (i.e. storage/installed). This tells the application that the database is already prepared.

Automobile POS VPS & Terminal CLI

VPS, Ubuntu & Terminal CLI Deployment

For sysadmins deploying on cloud instances (AWS EC2, DigitalOcean, Linode, Vultr, Hetzner), follow the standard artisan deployment commands below.

BASH CLI 
# 1. Clone or extract project into web server directory
cd /var/www/automobile-billing

# 2. Configure environment file
cp .env.example .env
nano .env

# 3. Generate production application key
php artisan key:generate

# 4. Run database migrations with standard seeders
php artisan migrate --force --seed

# 5. Link storage directory for public logos and barcodes
php artisan storage:link

# 6. Set directory ownership and permissions (www-data)
sudo chown -R www-data:www-data storage bootstrap/cache public/uploads
sudo chmod -R 775 storage bootstrap/cache public/uploads

# 7. Mark installer as completed
touch storage/installed

# 8. Optimize application routes and config cache
php artisan config:cache
php artisan route:cache
php artisan view:cache

Automobile POS Multi-Unit Conversion

Intelligent Multi-Unit Conversion Engine

Automotive workshops frequently buy inventory in bulk packages (boxes, cartons, barrels, drums) but sell items individually (pieces, litres, milliliters).

How Unit Conversion Works

Under Inventory → Units, you can define base units and secondary conversion multipliers. For example:

  • Engine Oil: Base Unit = Litre (LTR), Secondary Unit = Barrel (200 LTR)
  • Spark Plugs: Base Unit = Pcs, Secondary Unit = Box (10 Pcs)
  • Coolant: Base Unit = ml, Secondary Unit = Bottle (1000 ml)

When creating a purchase or selling in the POS, selecting "1 Box" of spark plugs automatically deducts 10 Pcs from your base warehouse inventory!

Automobile POS Customer Ledgers & FIFO

Customer Running Ledgers & FIFO Batch Allocation

Maintain transparent financial histories for fleet owners, corporate clients, and regular drivers.

How Customer Accounts Operate

  • Real-Time Running Balance: Tracks every invoice, return credit, and received payment chronologically with a live net balance.
  • Printable Account Statements: Generate date-filtered PDF account statements with opening balance, debit transactions, credits, and net closing balance.
  • FIFO Batch Settlement: When a customer makes a lump-sum payment (e.g. $500 towards multiple past unpaid bills), the intelligent FIFO (First In, First Out) engine automatically settles the oldest unpaid invoices first!
